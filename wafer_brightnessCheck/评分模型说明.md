# 晶圆亮度质量评分模型

## 模型概述

本评分系统基于数学模型对晶圆图像的亮度质量进行客观评估，满分100分。评分系统包含三个核心指标：

1. **肉眼直觉评分**（权重60%）- 基于人眼对亮度的感知特性
2. **平均亮度一致性评分**（权重40%）- 评估亮度分布的均匀性
3. **综合评分** - 两者的加权平均

---

## 1. 肉眼直觉评分模型

### 1.1 设计原理

人眼对亮度的感知并非线性，128灰度值（中等亮度）最为舒适。过暗或过亮都会降低视觉质量，但**高亮度的不适感通常小于低亮度**。

### 1.2 数学公式

使用**反常高斯分布**（Asymmetric Gaussian Distribution）：

$$
\text{Score}_{\text{visual}}(b) = 100 \times \exp\left(-\frac{(b - 128)^2}{2\sigma^2}\right)
$$

其中：
- $b$ 是图片的平均亮度值，$b \in [0, 255]$
- $\sigma$ 是标准差参数，控制曲线宽度：
  $$
  \sigma = \begin{cases}
  60 & \text{if } b \geq 128 \text{ (高亮度侧)}\\
  40 & \text{if } b < 128 \text{ (低亮度侧)}
  \end{cases}
  $$

### 1.3 曲线特性

- **峰值位置**：$b = 128$ 时，$\text{Score}_{\text{visual}} = 100$
- **对称性**：非对称曲线，高亮度侧更平缓
- **衰减速度**：
  - 高亮度侧（$\sigma = 60$）：衰减慢，惩罚小
  - 低亮度侧（$\sigma = 40$）：衰减快，惩罚大

### 1.4 评分示例

| 亮度值 $b$ | 偏离度 | 评分 $\text{Score}_{\text{visual}}$ |
|-----------|--------|-------------------------------------|
| 128 | 0 | 100.00 |
| 124 | -4 | 98.20 |
| 132 | +4 | 99.44 |
| 106 | -22 | 83.17 |
| 150 | +22 | 92.77 |
| 90 | -38 | 60.65 |
| 166 | +38 | 81.87 |

**观察**：相同偏离度下，高亮度（150）得分92.77，明显高于低亮度（90）的60.65

## 2. 平均亮度一致性评分模型

### 2.1 设计原理

评估所有图片亮度的一致性。理想情况下，所有图片的亮度应接近全局平均值，偏差越小说明照明越均匀。

### 2.2 数学公式

使用**指数衰减函数**（Exponential Decay）：

$$
\text{Score}_{\text{consistency}}(b_i) = 100 \times \exp\left(-\frac{|b_i - \mu_{\text{global}}|}{\lambda}\right)
$$

其中：
- $b_i$ 是第 $i$ 张图片的亮度值
- $\mu_{\text{global}} = \frac{1}{N}\sum_{i=1}^{N} b_i$ 是所有图片的平均亮度
- $\lambda = 20$ 是衰减速度参数（scale parameter）
- $|...|$ 表示绝对值，计算偏差

### 2.3 最终一致性评分

对所有图片的一致性评分求平均：

$$
\overline{\text{Score}}_{\text{consistency}} = \frac{1}{N}\sum_{i=1}^{N} \text{Score}_{\text{consistency}}(b_i)
$$

### 2.4 曲线特性

- **峰值位置**：$b_i = \mu_{\text{global}}$ 时，得100分
- **对称性**：完全对称，高于或低于平均值的惩罚相同
- **衰减规律**：偏差每增加 $\lambda = 20$，分数降至约 $36.8\%$（$e^{-1}$）

### 2.5 评分示例

假设 $\mu_{\text{global}} = 110$：

| 图片亮度 $b_i$ | 偏差 $\|b_i - \mu\|$ | 评分 $\text{Score}_{\text{consistency}}$ |
|---------------|---------------------|------------------------------------------|
| 110 | 0 | 100.00 |
| 115 | 5 | 77.88 |
| 120 | 10 | 60.65 |
| 130 | 20 | 36.79 |
| 90 | 20 | 36.79 |
| 150 | 40 | 13.53 |

## 3. 综合评分模型

### 3.1 加权平均公式

$$
\text{Score}_{\text{overall}} = w_1 \times \overline{\text{Score}}_{\text{visual}} + w_2 \times \overline{\text{Score}}_{\text{consistency}}
$$

其中：
- $w_1 = 0.6$ （肉眼直觉评分权重）
- $w_2 = 0.4$ （一致性评分权重）
- $w_1 + w_2 = 1$

### 3.2 权重设计理由

| 指标 | 权重 | 理由 |
|------|------|------|
| 肉眼直觉评分 | 60% | 直接影响人眼观察效果，是主要质量指标 |
| 一致性评分 | 40% | 保证晶圆不同位置亮度均匀，是辅助指标 |

## 7. 数学模型的优势

1. **客观量化**：将主观的"亮度质量"转化为可量化的分数
2. **符合直觉**：模型设计符合人眼感知特性
3. **可解释性强**：每个参数都有明确的物理意义
4. **可调节性**：参数可根据实际需求灵活调整
5. **可复现性**：相同输入必然得到相同评分

## 8. 技术实现

### Python实现示例

```python
import numpy as np

def visual_score(brightness):
    """计算肉眼直觉评分"""
    if brightness >= 128:
        sigma = 60  # 高亮度侧
    else:
        sigma = 40  # 低亮度侧
    
    score = 100 * np.exp(-((brightness - 128) ** 2) / (2 * sigma ** 2))
    return score

def consistency_score(brightness, global_mean, lambda_param=20):
    """计算一致性评分"""
    deviation = abs(brightness - global_mean)
    score = 100 * np.exp(-deviation / lambda_param)
    return score

def overall_score(visual_scores, consistency_scores, w1=0.6, w2=0.4):
    """计算综合评分"""
    avg_visual = np.mean(visual_scores)
    avg_consistency = np.mean(consistency_scores)
    return w1 * avg_visual + w2 * avg_consistency
```

## 9. 总结

本评分模型通过两个互补的评分指标，全面评估晶圆图像的亮度质量：

- **肉眼直觉评分**关注亮度的绝对值是否理想
- **一致性评分**关注亮度分布的均匀性

两者结合，既保证视觉效果，又确保一致性，为晶圆质量检测提供了科学、可靠的量化评估方法。
