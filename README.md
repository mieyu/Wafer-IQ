# Wafer-IQ 使用说明

这个项目用于批量执行晶圆图像检测流程，统一完成以下检查：

- 亮度检测
- 清晰度检测
- 位置偏移检测
- 形变翘曲检测

## 运行方式

在项目根目录执行：

```bash
python run_all_checks.py 输入路径 输出路径
```

例如：

```bash
python run_all_checks.py .\data .\output
```

含义如下：

- `输入路径`：待检测数据所在目录
- `输出路径`：检测结果保存目录，不存在会自动创建

## 输入目录要求

`输入路径` 下应放置一个或多个数据集文件夹，脚本会按数据集逐个处理。

示例：

```text
data/
├─ 数据集A/
├─ 数据集B/
└─ 数据集C/
```

程序会扫描 `输入路径` 下的所有子文件夹，并对每个数据集执行完整检测流程。

## 输出内容

结果会输出到你指定的 `输出路径` 下，并按数据集分别保存。每个数据集通常会生成类似下面的结构：

```text
output/
└─ 数据集A_输出/
   ├─ 亮度检测/
   ├─ 清晰度检测/
   ├─ 位置偏移检测/
   └─ 畸变性检测/
```

各检测模块一般会生成：

- `明细数据.csv`
- `评分报告.txt`
- 检测可视化图片 `.png`

## 可选参数

如果希望某个子任务失败后继续执行后续检查，可以添加：

```bash
python run_all_checks.py 输入路径 输出路径 --continue-on-error
```

## 使用建议

- 请在项目根目录下运行命令。
- 请确认 `输入路径` 存在，且里面至少包含一个数据集文件夹。
- 建议使用与你当前项目环境一致的 Python 解释器运行脚本。

## 最常用命令

```bash
python run_all_checks.py .\data .\output
```
